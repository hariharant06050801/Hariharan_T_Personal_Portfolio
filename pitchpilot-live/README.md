# PitchPilot

Cricket Tournament Operating System and Fixture Publishing Studio.

## Release
PitchPilot V9.3 — Simple Organizer

## Core capabilities
- Quick tournament setup
- Arbitrary and odd team counts
- Balanced groups
- Daily and weekday match capacities
- Fixture generation
- Match move and swap
- Conflict validation and alternate slots
- Undo and schedule history
- Match-day control room
- Results, standings and NRR
- Playoffs
- Poster/download centre
- Guided tour
- Simple and Advanced organizer modes
- Public read-only view

## Run locally
Open `index.html` in a modern browser.

## Deploy
This build is dependency-free. Deploy the folder to Vercel as a static project.

No AI agents or API keys are required.
